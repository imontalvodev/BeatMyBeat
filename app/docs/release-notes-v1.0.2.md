## English

**Title:** BeatMyBeat 1.0.2

### What's new

- **In-app updates:** tap **Download update** to fetch `BeatMyBeat.apk` from [GitHub Releases](https://github.com/imontalvodev/BeatMyBeat/releases/latest); the installer opens automatically when the download finishes.
- **Profile → Check for updates** still forces an immediate version check.

### Fixed

- **Playback queue:** resuming the app no longer resets the queue to the first track; shuffle order and position are restored.
- **Queue counter:** “tracks in queue” and “Up next” counts now update correctly while shuffle is on.
- **Analyze screen:** toast when URL or song field is empty before running analysis.

### Install

1. Download `BeatMyBeat.apk` from this release.
2. Allow installation from unknown sources if prompted (required for in-app updates too).
3. On Android 13+, grant media permissions when asked.

## Español

**Título:** BeatMyBeat 1.0.2

### Novedades

- **Actualizaciones in-app:** pulsa **Descargar actualización** para bajar `BeatMyBeat.apk` desde [GitHub Releases](https://github.com/imontalvodev/BeatMyBeat/releases/latest); al terminar la descarga se abre el instalador automáticamente.
- **Perfil → Buscar actualizaciones** sigue permitiendo comprobar la versión al momento.

### Corregido

- **Cola de reproducción:** al volver a la app ya no se reinicia desde la primera canción; se restauran posición y orden en shuffle.
- **Contador de cola:** «canciones en cola» y «A continuación» se actualizan bien con shuffle activo.
- **Pantalla Analizar:** aviso (toast) si la URL o el campo de canción están vacíos.

### Instalación

1. Descarga `BeatMyBeat.apk` de este release.
2. Permite instalar desde orígenes desconocidas si el sistema lo pide (también para actualizar desde la app).
3. En Android 13+, concede permisos de medios cuando se soliciten.
