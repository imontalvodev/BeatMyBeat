# BeatMyBeat 1.0.1

Notas del release publicado · tag `v1.0.1`

## English

**Title:** BeatMyBeat 1.0.1

### What's new

- **Update notification:** checks GitHub Releases on startup; tap **Go to beatmybeat.com** to download the new APK.
- **Profile → Check for updates** for a manual version check.

### Fixed

- Profile screen layout on small devices (scroll + responsive header).
- Update check no longer waits 12 h after a failed network request.

### Install

1. Download `BeatMyBeat.apk` from this release (or from [beatmybeat.com](https://beatmybeat.com)).
2. Allow installation from unknown sources if prompted.
3. On Android 13+, grant media permissions when asked.

## Español

**Título:** BeatMyBeat 1.0.1

### Novedades

- **Aviso de actualización:** comprueba GitHub Releases al abrir la app; pulsa **Ir a beatmybeat.com** para descargar el APK nuevo.
- **Perfil → Buscar actualizaciones** para comprobar manualmente.

### Corregido

- Diseño de la pantalla de perfil en pantallas pequeñas (scroll y cabecera adaptable).
- La comprobación de actualizaciones ya no espera 12 h si falla la red.

### Instalación

1. Descarga `BeatMyBeat.apk` de este release (o desde [beatmybeat.com](https://beatmybeat.com)).
2. Permite instalar desde orígenes desconocidas si el sistema lo pide.
3. En Android 13+, concede permisos de medios cuando se soliciten.
